# 🌿 Hydroponic Saffron Container Farm Blueprint

An interactive, data-driven operational and business model blueprint optimized for growing **Saffron (*Crocus sativus*)** inside a fully climate-controlled **40-foot High Cube shipping container** in challenging environments like Florida.

This repository hosts a standalone web application designed for AgTech entrepreneurs, investors, and hydroponic growers to simulate indoor saffron farming dynamics.

## 📋 Features

* **Spatial Capacity Modeling:** Visual breakdowns of a standard 40ft High Cube container compressing a 2.5-acre field footprint into ~300 sq. ft. using 5-tier vertical racks holding 75,000 corms.
* **Interactive Financial Engine:** A real-time calculator that projects annual gross revenues based on custom plant counts, target retail prices, and crop rotation frequencies.
* **⚡ Utility & Labor Trackers:** Custom parameter modules to input localized electricity rates ($/kWh), baseline power draw, picker wages, and harvesting speed to dynamically calculate true OPEX.
* **🗓️ Multi-Phase Climate Timeline:** An interactive operational schedule mapping out the precise temperature, light, and humidity cycles required to trick corms into blooming indoors.

## 🛠️ Local Setup & Deployment

### Quick Local View
1. Clone or download this repository to your local machine.
2. Double-click `index.html` to launch the interactive blueprint instantly in any modern web browser.

### GitHub Pages Deployment
This project is pre-optimized to run on GitHub Pages with zero build dependencies:
1. Go to your repository **Settings** tab.
2. Select **Pages** from the left-hand sidebar menu.
3. Under **Build and deployment**, set the Source to `Deploy from a branch`.
4. Choose the `main` (or `master`) branch, set the folder path to `/ (root)`, and click **Save**.
5. Your live application link will generate at the top of the page within 1–2 minutes.

## 📈 Operational Benchmarks Covered

The embedded logic leverages standard industry-validated agricultural data for indoor Saffron CEA (Controlled Environment Agriculture):
* **Yield Ratio:** ~75,000 high-grade corms yield 1 lb (453 grams) of pure dried red stigmas per single blooming cycle.
* **Byproduct Monetization:** Explores upcycling processing paths for purple petals (cosmetic extracts and dyes) and daughter corm replication metrics (asset scaling).
* **Climate Shock Requirements:** Pre-programmed with thermal boundaries ranging from 77°F (summer incubation) down to 50°F (flowering trigger) to successfully manage production cycles in warm climates.
